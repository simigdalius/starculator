# 🌟 STARCALATOR 

Μια διαδραστική εφαρμογή τερματικού (CLI) γραμμένη σε Python, σχεδιασμένη για να βοηθάει φοιτητές και ερασιτέχνες της αστρονομίας και της αστροφυσικής με βασικούς τύπους και υπολογισμούς.

##  Χαρακτηριστικά
- **Φιλικό UI στο Terminal:** Χρήση ANSI escape sequences για καθαρό, χρωματιστό και ευανάγνωστο μενού πλοήγησης.
- **Ασφαλής Εισαγωγή Δεδομένων (Safe Input):** Η εφαρμογή δεν κρασάρει αν ο χρήστης πληκτρολογήσει λάθος χαρακτήρες.
- **Μαθηματική Ακρίβεια:** Οι τύποι αναπαριστώνται με όμορφη στοίχιση και χρήση ειδικών χαρακτήρων Unicode (π.χ. ², ⁴, ⅓) για άμεση και εύκολη ανάγνωση.

##  Διαθέσιμο Τυπολόγιο
Αυτή τη στιγμή το Starcalator περιλαμβάνει τους εξής βασικούς τύπους της Αστροφυσικής:
1. **Νόμος του Stefan-Boltzmann:** `F = σ · T_eff⁴`
2. **Νόμος μετατόπισης του Wien:** `λ_max · T_eff = 2.9 × 10⁻³ m·K`
3. **Τύπος της φωτεινότητας:** `L = 4π · R² · σ · T⁴`
4. **Φαινόμενη λαμπρότητα:** `l = L / 4πr²`
5. **Πίεση ακτινοβολίας:** `P_rad = ⅓ u`  (ή `4σ·T⁴ / 3c`)
6. **Πυκνότητα ενέργειας ακτινοβολίας:** `u = 4σ·T⁴ / c`

##  Εγκατάσταση & Εκτέλεση

### Τρόπος 1: Άμεση Λήψη (Προτείνεται για Windows!) ⭐
Δεν χρειάζεται να εγκαταστήσετε Python ή να γράψετε κώδικα:
1. Πηγαίνετε στην ενότητα **Releases** στα δεξιά της σελίδας του GitHub.
2. Κατεβάστε το αρχείο **`starcalator.exe`**.
3. Κάντε διπλό κλικ στο αρχείο που κατεβάσατε και η εφαρμογή θα ανοίξει αμέσως!

### Τρόπος 2: Εκτέλεση από τον πηγαίο κώδικα (Για Developers & Mac/Linux)
Βεβαιωθείτε ότι έχετε εγκατεστημένη την **Python 3.x** στο σύστημά σας. Επίσης, η εφαρμογή χρησιμοποιεί τη βιβλιοθήκη `numpy`. 
1. Κάντε clone το repository στον υπολογιστή σας:
    `git clone [https://github.com/simidalius/starcalator.git](https://github.com/simigdalius/starcalator.git)`
2.Μεταβείτε στον φάκελο του project:
    `cd starcalator`
3.Τρέξτε την εφαρμογή:
    `python starculator.py`
4.Εγκατάσταση βιβλιοθήκης numpy:
    `pip install numpy`
